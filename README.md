# Insert Timestamp Plugin

**Автор:** Дурягин Егор, группа М3110. 
**IDE Plugin:** для IntelliJ IDEA  
**Версия:** 1.0  

##  Описание
Плагин добавляет действие *Insert Timestamp*, которое вставляет текущие дату и время
в активный редактор.

##  Возможности
- Вставка временной метки в формате `yyyy-MM-dd HH:mm:ss`
- Быстрый вызов с помощью `Alt + Shift + D`
- Поддержка любых текстовых редакторов в IntelliJ
